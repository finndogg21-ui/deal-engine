  working "See today's penny reports" link. `/totally-not-a-page` -> clean 404 page.
  All 15 routes return 200.

  "the register is the only truth" caveat, and a correct `?store=6550` deep link.
  Agent A: "the only page on the site that made me want to act."
- Card-to-detail text matched on all 3 cards compared.

## Agent A verdict (the customer)

**No — would not start a trial.** Not from disinterest: the hero and the penny
detail page sold them. They bounced because the site refuses to let them buy and
then says the invited action does not exist. Single biggest reason: **the product
cannot answer "is it at my store?", the only question they had** — ZIP typed, API
returned Bitters Rd at 3.6 mi with real per-item stock, and the interface showed
none of it.
